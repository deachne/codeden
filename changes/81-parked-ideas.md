- Parked ideas: the dark factory's scout now keeps the good ideas it doesn't file in a "Parked ideas" list, each with why it liked the idea and why it was set aside, and copies each one to an issue in your Ideas repository (`factory.ideasRepo`, default `deachne/ideas`, labelled `codeden`). A badge in the Factory panel counts them; **Build it** files one as normal factory work, **Not now** hides it and labels its Ideas issue `someday`. Ideas you never touch are hidden after 60 days, never deleted, and an Ideas repository that can't be reached never holds up a round.
