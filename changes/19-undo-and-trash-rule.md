section: fixed

- **Explained approvals say "can be undone" when it can.** An edit, or a command that deletes nothing and sends nothing off the machine, inside a session's own worktree now shows "Yes" under **Can it be undone**, since the turn checkpoints can put it back. Deletions, pushes, publishes, network tools and anything outside the worktree still show "No".
- **The Trash rule only goes where there is a Trash.** With **Delete to the Trash** on, agents on a Mac are told to use the Trash; agents on Linux, Windows, in Docker or a cloud sandbox no longer get a rule they can't follow. Settings says so.
