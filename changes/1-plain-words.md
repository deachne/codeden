- **Explain changes in plain words.** A new per-project setting (Settings > General, off by default) has every agent that opens a pull request start its description with a short note in everyday words: what changed for you, how to try it, what wasn't checked and how to undo it. The work item's page, the Factory view's side sheet and the inbox card of a pull request to review show that note first. A missing note is flagged by the reviewer as a follow-up and never holds up a merge.
