- **Approving a plan gets work going.** When you approve a project's plan, its PM wakes up, turns the first version into a few small jobs and, in Assisted mode, starts the first one and tells you (in Manual mode it suggests it instead). The Planner now also hands over how you'll check it works as owner checks, which you can edit or remove on the project page. They stay out of the plan file, because builders read the plan and never see owner checks. The PM no longer runs its own round of questions beside the Planner: it points you to **Plan with me**, and plans with you itself only if you'd rather.
