- **Earned auto-merge per kind of work.** In factory settings, auto-merge can now be gated separately for docs, bugs, and features instead of one single project switch. Each kind can be set to earned, always, or off (features stay with the owner by default). A kind set to earned merges on its own only after its last N items in the scorecard passed first time with no revise rounds, no reverts, and no spot-check problems.
