- **A project plan beside the vision.** Each project can have a plan, `.codeden/PLAN.md`, edited on the new **Plan** page: the first version, the technical route, what waits, how you'll check it works and the questions still open. Builders, reviewers, the scout and every session a PM starts get it in their brief (cut to 6,000 characters), and approving a project's plan records which version of it you read. In a GitHub project, saving it opens a small pull request, as the vision does. Like the vision, it's a protected file: no agent change to it merges by itself.
