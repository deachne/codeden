- **Plan a new project before agents build in it.** A project added from now on starts in planning: until you press **Approve plan** on its project page, CodeDen starts no agent session that a PM, the orchestrator, an automation or the factory asks for, and the software and dark factory stay off. Sessions you start yourself still run, and the PM plans with you meanwhile. Approving records which version of the vision you read. Projects you already have count as approved and keep running as before.
