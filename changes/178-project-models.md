- **A model for each project's project manager and workers.** Project → Settings → "Models for this project" has two pickers, one for the project manager and one for its workers (the sessions the PM, the factory and automations start there). Left on "Follow shared setting", a project uses Settings → Providers as before. A model named when something is started still wins. If a choice can't be used later (the model was removed or the tool is signed out), the shared setting is used instead and the Inbox says so. Changing the project manager's model starts a fresh conversation with it, and the page says so before saving.
