- **A feature map for each project.** Each project can now have a plain list of every screen and button a person can reach, in your own words (`.codeden/FEATURE_MAP.md`, with "(planned)" on what isn't built yet), so you, the agents and your owner checks all use the same names. **Plan with me** drafts it with you: for a project that already exists, the Planner reads the code and then checks each screen with you, one question at a time, and it writes your owner checks with the map's names. Edit it on the new **Feature map** page, opened from the Plan page; in a GitHub project, saving it opens a small pull request, as the plan does. Builders, reviewers, the scout, the owner-check tryout and every session a PM starts get it in their brief (cut to 4,000 characters). Like the rest of `.codeden/`, it's a protected file: no agent change to it merges by itself. Your owner checks stay hidden from builders.
