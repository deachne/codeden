- **An Update button for a copy run from its own folder.** Set an update script in Settings > General > Update script (one that gets the latest, rebuilds and restarts CodeDen) and an Update button appears at the top of the sidebar. A dot shows when GitHub has new changes. It asks before it starts, shows "Updating…", and the page reloads by itself when CodeDen is back. If the script fails, CodeDen keeps running and the button shows what went wrong. The script path can only be changed on the computer running CodeDen; any signed-in device, like a phone, can press the button.
