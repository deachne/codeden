- **Plan with me.** A new project's plan card, and the Plan page, have a **Plan with me** button. It starts a Planner session that reads what the project already has, tells you what it found in plain words, then asks you one question at a time, each with its recommended answer. When you say yes, it writes the vision and the plan and hands them over (in a GitHub project, a small pull request for each), and the card asks you to read them and press **Approve plan**. The Planner builds nothing, runs read-only where the provider allows it, and can never approve the plan itself. Pick its model under **Settings > Providers > Defaults per role > Planner**.
