- **The factory suggests turning a lesson that keeps coming back into an automatic check.** When two of the factory's lessons say the same thing (judged in plain meaning by the utility model, not by exact words), or one lesson is recorded again by other work, one Inbox card asks "The same mistake keeps coming back: add a lint rule / test / type check to stop it?". It names the lessons, how many fix rounds they cost and what kind of check would stop it. **Build the check** files an ordinary issue that goes through the usual review; **Not now** closes the card and the same lessons are not suggested again. It only suggests: nothing is built or merged on its own.
